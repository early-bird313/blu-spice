# Blu Spice | Tangail - Restaurant Website

অফিশিয়াল রেস্টুরেন্ট ওয়েবসাইট প্রজেক্ট - **Blu Spice (College Para, Tangail)**।

## 🌟 ফিচারসমূহ (Features):
- **মডার্ন ও রেসপনসিভ ডিজাইন:** মোবাইল ও কম্পিউটার সব ডিভাইসে দারুণ লুক।
- **ডিজিটাল ফুড মেন্যু:** পিৎজা, মেক্সিকান পিৎজা, ক্রিস্পি চিকেন, বার্গার, পাস্তা এবং ড্রিংকস ক্যাটাগরি।
- **লাইভ সার্চ ও ফিল্টার:** এক ক্লিকে যেকোনো খাবারের আইটেম খুঁজে বের করার সুবিধা।
- **ডিরেক্ট হোয়াটসঅ্যাপ অর্ডার (WhatsApp Cart):** খাবার কার্টে যোগ করে নাম-ঠিকানা দিলে সরাসরি ব্লু স্পাইসের হোয়াটসঅ্যাপে ফরম্যাটেড মেসেজ চলে যাবে।
- **গুগল ম্যাপ ও লোকেশন:** কলেজ পাড়া, টাঙ্গাইল লোকেশন ও ডিরেকশন।

## 🚀 Vercel-এ ডিপ্লয় করার সহজ নিয়ম (Deploy to Vercel):

### অপশন ১: টার্মিনালে ১টি কমান্ড দিয়ে (সবচেয়ে দ্রুত)
১. টার্মিনালে রান করুন:
```bash
npx vercel
```
২. প্রথমবার হলে এটি আপনার ব্রাউজারে লগইন করতে বলবে (GitHub বা Email দিয়ে লগইন করুন)।
৩. এরপর ৩-৪ বার শুধু `Enter` চাপলেই ১ মিনিটে আপনার লাইভ লিঙ্ক (যেমন: `https://blu-spice-tangail.vercel.app`) তৈরি হয়ে যাবে!

### অপশন ২: GitHub দিয়ে
১. এই প্রজেক্টটি আপনার GitHub অ্যাকাউন্টে পুশ করুন।
২. [vercel.com](https://vercel.com)-এ গিয়ে **Add New Project** সিলেক্ট করে রিপোজিটরি ইমপোর্ট করুন।
৩. কোনো কনফিগারেশন ছাড়াই **Deploy** বাটনে ক্লিক করুন।
